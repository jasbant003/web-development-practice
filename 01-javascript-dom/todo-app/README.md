# Todo Application

A simple Todo application built using HTML, CSS, and Vanilla JavaScript to practice DOM manipulation and event handling.

## Features

- Add new tasks.
- Display tasks dynamically.
- Delete individual tasks.
- Use icon-based buttons for task actions.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Concepts Practiced

- DOM manipulation
- `createElement()`
- `appendChild()`
- `addEventListener()`
- `classList.add()`
- `innerText` and `innerHTML`
- DOM traversal using `parentNode`
- Dynamically creating and removing HTML elements
- Handling user input

## Purpose

Built as a hands-on project to improve my JavaScript fundamentals and gain practical experience working with dynamically generated DOM elements and browser events.
