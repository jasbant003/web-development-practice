# CRUD Application

A simple CRUD (Create, Read, Update, Delete) application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add new records through an HTML form.
- Display records dynamically in an HTML table.
- Edit existing records using the form.
- Delete individual records.
- Reset form fields after submission.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Concepts Practiced

- DOM manipulation
- `getElementById()` and `querySelector()`
- `createElement()`, `insertRow()` and `insertCell()`
- `appendChild()` and `remove()`
- Event handling
- DOM traversal using `parentNode` and `closest()`
- Working with JavaScript objects
- Dynamically updating HTML table elements

## Purpose

Built as a hands-on project to strengthen my understanding of JavaScript DOM manipulation, event handling, and CRUD operations.
